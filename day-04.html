贯穿今天的一个问题

“去把隔壁房间桌上的杯子拿过来。”

杯子在任务空间里的哪里？机械臂的工作空间覆盖它吗？覆盖了，关节角在限位内吗？限位内，肘部会不会撞到桌沿？都没有问题，控制器跟得上吗？

今天只用两连杆，但结论不是玩具

平面二连杆是所有机械臂里最简单的模型：两段长度 l1、l2，两个关节角 q1、q2。它已经能完整暴露 FK、IK、Jacobian、奇异位形、关节限位这五件事的全部结构。

六轴机械臂只是把这个结构重复堆叠、再加三维旋转。两连杆想不清楚，六轴只会更糊。所以今天不碰 DH 参数，不碰四元数。

“角度用度还是弧度”为什么会算错？

本页所有推导用弧度，界面显示用度。程序里 sin(90) 算的是 90 弧度，不是 90 度——这是运动学作业里最常见的第一个错误。拖动滑条时注意看输出：界面写 90°，公式里代入的是 π/2 ≈ 1.5708。

正运动学 FK
给关节角，算出末端在哪。一个输入只有一个答案。
逆运动学 IK
给末端目标，反推关节角。可能无解，可能两组解，选哪组是策略问题。
可达域 / 工作空间 workspace
末端实际能到达的位置集合。它常常是个环，而不是一个圆。
关节限位 joint limit
数学上有解，机械结构不允许。很多“解不出来”其实是“转不过去”。
雅可比 Jacobian
一张换算表：关节转一点点，末端在各个方向上动多少。
奇异位形 singularity
某个方向上末端忽然动不了（手臂完全伸直的那一刻），逆解会在这里爆掉。

01 对应 14plan Day 4 · 第 1 阶段

构型空间、工作空间、任务空间
是三个不同的地方。

这三个词经常被混着说，一混，后面的判断就全错。它们回答的是不同的问题，写在不同长度的向量上。

名字装的是什么两连杆里的维数回答的问题
构型空间（configuration space）描述机器人自身姿态的那组独立参数2 维：(q1, q2)机器人现在是什么姿势？
工作空间（workspace）末端在所有合法构型下能到达的位置集合2 维：(x, y) 的一个环形区域末端最远能伸到哪？
任务空间（task space）任务本身关心的量：位置、姿态、力这里取 2 维位置；真实抓取还要 3 维姿态任务要求末端处于什么状态？
关键的不对称

FK 是一对一的：给定 (q1, q2)，末端位置唯一。IK 是多对一甚至无解的：一个末端位置可能对应两组关节角，也可能一组都没有。所有“逆解难”的问题，根源都在这个不对称上。

还有一个更隐蔽的坑：工作空间是几何集合，不是可行性证明。“这个点在可达域里”只说明存在某个关节角能到，不说明那个关节角在限位内，更不说明沿路不撞东西。

02 Forward Kinematics · 正运动学

给两个角度，
算出末端在哪。

第一段从基座出发，方向由 q1 决定；第二段的方向是 q1 + q2——注意是加起来，因为 q2 是相对第一段的角，不是相对世界坐标的角。这一步搞错，后面的雅可比会全错。

x = l1cos(q1) + l2cos(q1+q2)　　y = l1sin(q1) + l2sin(q1+q2)

动手看

先把 q1 拖到 0°、q2 拖到 90°。预测末端落在哪，再看读数：应该是 (1, 1)。然后把 q2 改回 0°，看机械臂变成完全伸直。

平面二连杆 · 改角度看末端l₁ = l₂ = 1 m
末端 x（m）1.000
末端 y（m）1.000
|J| = l₁l₂·sin q₂1.000

手算一遍，再对照屏幕

取 q1 = 0°、q2 = 90°，即 π/2 弧度：

x = 1·cos0 + 1·cos(0+π/2) = 1 + 0 = 1　　y = 1·sin0 + 1·sin(π/2) = 0 + 1 = 1

第一段沿 +x，第二段垂直向上，末端落在 (1, 1)。长度也对得上：两点距离 √2 ≈ 1.414，正是等腰直角三角形的斜边。

03 Workspace · 可达域

可达域是一个环，
不是一个圆。

两段各 1 m 的机械臂，末端最远到 2 m（完全伸直），最近到 0 m（完全折回）。如果两段不等长，中间会挖掉一个洞：最近只能到 |l1 − l2|，那个小圆盘是盲区。

04 Joint Limits · 关节限位

数学上有解，
关节不一定允许。

把两个关节的允许范围都限制在 [−45°, 45°]。目标还是 (1, 1)：几何上它明明白白在可达域里，两组解却分别是 (0°, 90°) 和 (90°, −90°)——没有一组落在限位内。

打开限位，看哪组解还活着±45°
解q₁q₂是否在限位内
可用解2 / 2
结论可达且可执行

三种判断必须分开写

① 目标在工作空间内（几何）；② 逆解落在关节限位内（机械约束）；③ 从当前姿态到该解无碰撞（路径约束）。三条都成立才叫“可执行”，写成一句话就会漏掉后两条。

05 Inverse Kinematics · 逆运动学

逆解有两组，
选哪组是策略问题。

平面两连杆有解析解，不需要迭代。先由余弦定理求出 q2，再反推 q1：

cos q2 = (r² − l1² − l2²) / (2 l1 l2)　　q2 = ± arccos(…)

q1 = atan2(y, x) − atan2(l2sin q2, l1 + l2cos q2)

正负号给出两组解，就是上一节图里“肘上 / 肘下”两条手臂。两组都到达同一个点，但肘部扫过的空间完全不同——这正是抓取姿态会影响后续通行的原因。

情况数学表现该怎么报
目标太远r > l₁ + l₂，cos q₂ < −1无解；可给出“最近可达点”作为参考，但不能当成解
目标太近r < |l₁ − l₂|，cos q₂ > 1无解；中间盲区
恰在边界cos q₂ = ±1唯一解（退化），此时处于奇异位形
有解但超限位解存在，q 越界报“逆解存在但不可用”，不要说“无解”
停一下：为什么六轴机械臂一般不用解析解，而用数值迭代？

六轴带三维旋转后，解析解要按腕部构型分支讨论，公式长且对奇异敏感。工程上常用数值迭代（雅可比伪逆、阻尼最小二乘），代价是要给初值、可能收敛到不同分支、也可能在奇异附近震荡。“有解析解”是两连杆的特殊福利，不是通例。

06 Jacobian · 雅可比

关节转一点，
末端动多少？

把 FK 的两个式子分别对 q1、q2 求偏导，得到 2×2 雅可比矩阵。它做的事是把关节速度映射成末端速度：ẋ = J(q)·q̇。

J = [ −l₁sin q₁ − l₂sin(q₁+q₂)　−l₂sin(q₁+q₂) ;　l₁cos q₁ + l₂cos(q₁+q₂)　l₂cos(q₁+q₂) ]

图里那个椭圆，就是把“关节速度取单位圆”映射到末端后得到的形状。椭圆越扁，说明某些方向的运动越困难；扁成一条线，就是奇异位形。

姿态J 的数值|J|含义

拖动上面的 q1／q2 滑条，这张表和椭圆会一起变。先预测 q2 = 0° 时 |J| 是多少。

行列式的几何意义

|J| 是“关节空间单位面积”映射到“任务空间面积”的缩放比。它趋近 0，意味着有一整个方向的运动被压没了——关节怎么动，末端都动不了那个方向。

07 Singularity · 奇异位形

伸直的那一刻，
手臂少了一个方向。

代入 q2 = 0：两段共线，末端只能沿径向伸缩，无法沿切向移动。|J| = l₁l₂ sin 0 = 0。这就是奇异位形。

三种后果，按严重程度排：

  1. 逆解退化

    边界上两组解合并成一组，无法再通过“换一组解”绕开障碍。

  2. 数值求解发散

    雅可比不可逆，伪逆在奇异附近数值爆炸，关节速度出现尖峰。工程上用阻尼最小二乘（DLS）压制，代价是末端精度下降。

  3. 力传递失效

    奇异方向上末端对外力的抵抗能力趋近于零。推门时如果正好在这个方向，手臂会被门推着走。

停一下：为什么“避开奇异”不能只靠“别让 q₂ 等于 0”？

因为奇异不是单个点，而是构型空间里的一片区域（这里是 q2 = 0 与 q2 = π 两条线）。而且实际任务的目标点可能只有经过奇异附近才连得上——这时要做的是路径规划时加惩罚项或绕行，而不是假装它不存在。

这张表就是“为什么环境生成不等于运动控制”的答案：每一层都有自己的输入、输出和失败模式，上一层通过不蕴含下一层通过。
