## 3. 今天必须分清的几组概念

| 概念 | 今天采用的准确解释 |
|---|---|
| SAT 与 SMT | SAT 研究布尔公式有没有满足赋值；SMT 在公式中加入带既定含义的理论，例如整数与实数算术。Z3 能处理多种理论，具体能力取决于输入公式。 |
| `Int` 与 `Real` | `Int` 是无界数学整数，不是机器定长整数；`Real` 表示数学实数。选 `Int` 会增加“坐标取整数”的建模条件。 |
| `And` 与 `Or` | 总要求通常要一起成立；两个正面积轴对齐矩形不内部重叠，只需四种分离关系至少一种成立。允许接边使用 `<=`。 |
| `sat`、`unsat`、`unknown` | 分别是找到满足已编码公式的模型、证明这些公式不相容、当前求解调用未能判定。`unknown` 的原因要读取并原样记录。 |
| 模型与最优解 | `Solver` 找一个可行模型；有多个可行模型时，它无须选择“最好看”的那个。Z3 另有 `Optimize` 接口处理目标与软约束。 |
| 核心与修复 | `unsat_core()` 返回可用于解释本次不可满足的跟踪标签或假设子集。核心需结合未跟踪背景理解，不等于唯一根因或直接删除清单。 |
| 极小与最小 | “按包含关系极小”是再删任一成员就不再构成该冲突；“元素数量最小”还要和其他核心比较。默认核心不保证满足这些更强条件。 |
| 求解与后验验证 | 求解器只回答公式中的问题。未编码的接面、净空、动作或实际运动需要相应检查器或执行验证。 |

对于输入常数，示例使用 `RealVal("0.8")` 等精确有理数写法。Python 3 的普通 `3 / 2` 会先产生 Python 浮点数；需要精确分数时使用 `Q(3, 2)` 或 `RealVal(3) / 2`，不要沿用旧版本的 Python 除法说明。

## 4. 六例教学参考怎样连接到自己的练习？

先写下自己的变量、单位、约束、预测与理由，再展开网页中的参考结果。下面六例来自任务手册给定的变体，是教学核对材料；自己的验收案例仍需保留首次预测和实际操作记录。

| 编号 | 输入与条件 | 教学预期 |
|---|---|---|
| S1 | 两间 2×2 房，放入 4×3 边界 | SAT |
| S2 | 两间 2×2 房，放入 5×5 边界 | SAT |
| S3 | 一间 2×2 房，放入 2×2 边界 | SAT |
| U1 | 两间 2×2 房，放入 3×3 边界 | UNSAT |
| U2 | 一间 2×2 房，放入 1×3 边界 | UNSAT |
| U3 | 同一门净宽同时要求 ≥0.8 m、≤0.5 m | UNSAT |

S1–U2 的 Python 实验与原 MiniLab 一样：位置变量是 `Int`，长度单位为米，房间轴对齐、尺寸固定，允许边界接触，不允许内部重叠。U3 的门宽用 `Real`。图形中连续滑动的解析示意与整数求解模型分别标注。

为核对这个区别，实验额外把 U1 的位置变量改为 `Real`，实际结果仍为 `unsat`。这是 2×2 房放入 3×3 边界这一特例的结论；通常不能仅凭整数模型无解，就断言放宽到连续坐标仍然无解。

4. 实际 `sat/unsat/unknown`、模型或核心、耗时、版本；未运行就保留“未运行”。
5. 这套公式没有检查哪些要求，以及接下来的独立验证。

现成示例展示了 `unknown` 的真实结果与原文原因，不能把任意 `unknown` 改写成“超时”。单次耗时也不能作为速度优势或性能排名。
